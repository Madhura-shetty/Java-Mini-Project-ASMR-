# ASMR To-Do List

A simple **To-Do List desktop application built using Java Swing**. The application provides a graphical interface for adding and managing tasks in an organized list.

## Features

* Add new tasks
* Display tasks in a structured list
* Track task numbers
* Mark and manage completed tasks
* Clear completed tasks
* Simple and user-friendly graphical interface

## Technologies Used

* **Java**
* **Java Swing**
* **AWT**

## Project Structure

* `ToDoList.java` – Main class used to launch the application
* `AppFrame.java` – Creates and manages the main application window
* `titleBar.java` – Defines the application title bar
* `ButtonPannel.java` – Contains task management buttons
* `list.java` – Manages the task list and task numbering
* `task.java` – Represents individual tasks

## How to Run

1. Clone the repository.
2. Open the project in a Java-supported IDE such as IntelliJ IDEA, Eclipse, or NetBeans.
3. Make sure Java is installed on your system.
4. Compile the Java files.
5. Run `ToDoList.java`.

## Purpose

This project was developed as a mini project to practice **Java programming, object-oriented programming, and GUI development using Java Swing**.
